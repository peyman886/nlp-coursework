# NLP & LLM — Coursework

Assignments and projects from four natural language processing and large
language model courses, from classic Persian text processing to parameter-
efficient fine-tuning, RAG and RLHF. Notebooks are committed with outputs.

## 1402-2 · NLP, Dr. Yaghoubzadeh (Khatam University)

| Folder | Topic |
|---|---|
| [`HW1`](1402-2-yaghoubzadeh/HomeWork/HW1) | Statistical word embeddings, dimension reduction, pre-trained embeddings and a first Hugging Face fine-tune |
| [`HW2`](1402-2-yaghoubzadeh/HomeWork/HW2) | Transformers from scratch: scaled dot-product and multi-head attention |
| [`HW3`](1402-2-yaghoubzadeh/HomeWork/HW3) | Generative language models: decoding with beam search, cross-attention maps |
| [`HW4`](1402-2-yaghoubzadeh/HomeWork/HW4) | Text classification with BERT |
| [`Project`](1402-2-yaghoubzadeh/Project) | *Evaluating LLMs as a recommendation system* — ChatGPT and Llama without fine-tuning |
